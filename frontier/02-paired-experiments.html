Agent 前沿进阶能力增长、自主研究与自我改进

第 02 章｜多做了几题，能确定 Agent 改好了吗

本章概览

核心问题：同一改进在几次运行中多成功了，怎样区分观察到的差值、任务差异与抽样不确定性？

关键概念：任务：带初态和合同的问题；试次：从重置状态开始的一整次执行；配对差：两方案在同一任务上的差值；标准误：均值随抽样波动的尺度；置信区间：在条件成立时具有重复覆盖含义的区间构造。

关系主线：先把重复运行归回任务，再从八题例子算均值、方差与区间；用同源题、未知评分和更多重复的反例，解释下一项实验该补任务还是补试次。

先定义要推广到哪些任务

硬前置是第01章。沿用其中的两个输入政策：Q0使用原说明；Q1在第一次执行失败后加入固定诊断提示，要求比较原动作与程序实际收到的参数。两边使用同一模型、工具与每次预算，面对相同的待修文件。Q1的额外读取也占预算；本章比较这整套输入政策，暂不将收益拆成提示长度和诊断步骤各自的作用。

为演算，另构造八个代码维护任务 U1–U8，分属路径参数、入口发现、错误传播与文档范围四类。它们是课程写定的文件/合同场景，不是公开 benchmark 或真实模型成绩。每题两方案各执行4个计划试次；一个试次可以含多轮模型与工具调用。每次从相同项目初态开始，不继承前次补丁、消息或跨题记忆；模型、资源、工具权限与120秒截止一致。

真实研究还需先说明：想推断的是这八个固定任务上的表现，还是某个项目总体中的新任务表现。多跑同一题能增加对这一题稳定性的认识，却不会自动增加新项目的覆盖。 本例先示范“每个任务等权”的比较方法，再交代向未来任务推广的条件。

S表示判定器正常工作后确认合同成功，F表示有有效判定但合同失败。这里暂时没有未知评分，所有费用也结清；缺失情况在后面单独改变条件。表内序列依次对应四个完整试次，不是四条测试断言。

第一试次Q0为5/8、Q1为6/8，差12.5个百分点；四次全部计入后Q0为16/32、Q1为22/32，差18.75个百分点。两个数字都可以算对，但用的是不同观察范围。看到第二、三次不利结果就提前停止或只报最好一次，会再次改变问题。

先在题内平均，再在题间比较

用下标 i 表示任务，r 表示该任务的重复试次，a 表示政策Q0或Q1。令 y[a,i,r] 为有效结果：S取1，F取0。所有数均无量纲；0.1的成功比例差对应10个百分点。

在本例每题4次的条件下：

p̂[a,i] = (y[a,i,1] + y[a,i,2] + y[a,i,3] + y[a,i,4]) / 4
d[i] = p̂[Q1,i] − p̂[Q0,i]
Δ̂ = (d[1] + … + d[N]) / N，N = 8

帽子 ^ 表示从有限观察得到的估计；p̂ 是一题的观测成功比例，d是任务配对差，Δ̂是任务等权的平均差。若使用概率语言，p[a,i]表示在所声明运行条件下，对同一题重复执行时成功的概率；它不是已知常数，p̂只是估计它的一种方式。

逐题得到：

d = [0.25, 0.50, 0, 0.25, −0.25, 0.50, 0, 0.25]
差值之和 = 1.50
Δ̂ = 1.50 / 8 = 0.1875

U5明确退化，U3/U7没有观察到收益。平均值把这些差异合并，却不取消它们。保留逐题数据可以追问：新提示是否诱导U5额外加工错误信息，是否存在不同机制的相反影响。

现在改变一个条件：若为了排查U1，把它跑40次，其余每题仍4次，直接汇总所有试次就会大幅提高U1的权重。如果目标依然是“每个任务同等重要”，应先在各题内分别平均，再对8个题均值等权。反过来，若实际业务里某类任务占比很高，可以使用预先定义的任务权重；权重应来自要评价的分布，不能因为哪类题涨分更多就事后放大。

“配对”指两政策面对同一任务合同与初态。相同的试次编号不保证模型随机数相同；两边一次API调用数不同，也不能硬把第3次调用当成自然配对单位。为降低时间漂移的影响，真实执行可以按预先安排交错Q0/Q1或随机化次序，并记录服务事故；这不会自动消除同题或同源任务的相关性。

平均差周围还有多大的波动

若换一批任务，或同题换一批模型采样，差值会变化。期望是按指定抽样机制反复观察时的平均；方差是围绕这个平均的平方偏离，用于表示波动。平方使正负偏离不相互抵消。标准差是方差开平方，单位回到原来的比例差。

先用八个观测差值估计题间离散程度。设 d̄=Δ̂=0.1875，差值的样本方差为：

s_d² = Σ_i (d[i] − d̄)² / (N − 1)

Σ_i表示把八题对应项相加，N−1=7。因为均值也是用这八项估出的，八个偏离的和必为0，只有七个可以自由变化；在独立同分布抽样条件下，用7作分母得到通常的样本方差估计。

本例有三个0.25、两个0.50、两个0和一个−0.25，因此：

平方偏离之和
 = 3×(0.25−0.1875)² + 2×(0.50−0.1875)²
   + 2×(0−0.1875)² + (−0.25−0.1875)²
 = 0.46875
s_d² = 0.46875 / 7 ≈ 0.066964
s_d ≈ 0.258775

这里方差用比例差的平方计量，标准差与标准误回到比例差尺度。各题的观测差也含四次重复造成的采样波动，不能把它全部称为纯粹的题目难度差。

若这些任务差值可看作独立、来自相同的抽样机制，均值的方差约为单题方差除以N，标准误为 SE=s_d/√N≈0.091491。这个除法依赖独立性：平均多个共享同一错误来源的观察，不能按同样速度消除共同偏差。

接着示范一个常见的t区间构造：

d̄ ± t[0.975, N−1] × SE
 = 0.1875 ± 2.364624 × 0.091491
 ≈ [−0.028841, 0.403841]

这里选择双侧95%水平，给两端各留2.5%；t[0.975,7]是自由度7的t分布97.5%分位值。乘积约0.216341是区间半宽。换成百分点，端点约为 −2.88到+40.38个百分点。

这个公式在独立正态差值的设定下有相应覆盖保证；真实Agent任务差值常有界、离散、异质且相关，需要检查近似是否适用。本表只有八个教学构造任务，上式只是区间计算示范，不是一个已证实具有95%覆盖的Agent实验结果。若任务真由合适的分布独立抽样且任务数量足够，近似才更有依据；小样本、偏斜或来源组相关时应选择匹配设计的统计方法，不能靠换一个公式名称获得保证。

“95%”说的是：按同样抽样与构造方法不断重复，所得区间在相应条件下约95%会覆盖固定的总体均值差。它不是在这次算完后，给固定未知差值分配95%的落区间概率。区间也不包含未控制的环境变化或评价泄漏造成的系统偏差。

即使暂按该近似阅读，区间含0，也只能说尚不能排除零差异；它还包含退化和明显收益，不能证明两方案等效。若采用条件是“至少提高5个百分点”，本区间也不足以确认，因为下端低于+5。观察均值18.75、推广收益至少5、证明没有退化，是三个不同主张。

将例算交给一个保持分组的程序

以下可执行参考程序用正文给定的成功数重算均值、方差和区间。它没有运行Agent，也没有检查抽样假设；临界值在这里是本例自由度7的给定常数，不能原封不动用于其他样本量。

import math

q0 = [3, 1, 4, 2, 3, 0, 2, 1]
q1 = [4, 3, 4, 3, 2, 2, 2, 2]
repetitions = 4
d = [(b - a) / repetitions for a, b in zip(q0, q1)]
n = len(d)
mean = sum(d) / n
variance = sum((x - mean) ** 2 for x in d) / (n - 1)
se = math.sqrt(variance / n)
t_critical = 2.364624251  # 仅对应本例95%双侧、df=7
low, high = mean - t_critical * se, mean + t_critical * se
print(f"mean={mean:.6f}; SE={se:.6f}")
print(f"interval=[{low:.6f}, {high:.6f}]")

本地例算输出是：

mean=0.187500; SE=0.091491
interval=[-0.028841, 0.403841]

代码只用八个题差值计算SE，未把64次双侧执行或更多工具调用当成64个独立任务。输入如果含未知，不能用 None转0后继续套本例。

同源题和未知结果会怎样改变判断

先改变来源条件：假设U1/U2其实是同一模板改了目录名，U3/U4也共享一份入口模板。它们可能共享难点和错误机制，不能再宣称八份独立任务来源。应保存来源组，按希望推广的层次分组划分和分析。若用重采样，抽到一组时要一并带上该组相关任务及两侧结果；逐行打散会破坏原来的关系。组数很少时，重采样本身也不能制造更多独立证据。

再单独改变评分条件，恢复原八题来源设定，假设Q1的U5第2次评分服务失败。原表这一格F改为未知U；已知成功仍22，已知有效失败9，另有1个未知。有效评分条件率为22/31，却不能与Q0的16/32直接当成整体收益。

对Q1全部32个计划试次，任务成功比例的逻辑范围是22/32到23/32；差值范围是18.75到21.875个百分点。它只枚举未知格可能为0或1，不是置信区间。若定义截止确认交付，U贡献0表示截止未确认成功，原始任务分数仍为未知。两个口径可以并列报告，不能互相改写。

来源相关性与未知评分解决不同问题。把U排除后计算得再精确，也不能说明失去评分的题与其余题相似；保留所有行又不意味着可以忽略来源组。完整统计记录必须留住任务身份、试次、初态、评分状态、成本与处理规则。

下一项实验应该补什么

假设还够新增16次单侧执行，即8个新的Q0/Q1配对试次，可以花在两种位置：在原八题各补一对，或新增八个来源清楚的任务各做一对。前者主要帮助看清已选题的运行变动，后者主要扩展任务覆盖，但每个新任务的一次结果又较吵。选择取决于当前不确定性来自哪里。

若原题各次表现很稳定，而不同机制有明显正负差，应优先增加独立任务覆盖并追查U5退化。若题间类似但同题采样波动很大，应先补重复。这个小表不足以精确分解两种方差，所以应把这作为下一项设计判断，而非已证明的最优预算分配。

还需累计完整成本。本表两方案各32试次，共64次任务执行。若每次连同验证固定消耗2个教学费用点，总执行费128点；Q1提示制作另花6点，则本次研究总费134点。重复或新增任务每加一对再花4点。费用点是教学计量，不是真实价格；失败成本已在64次内，不能只为22次成功收费。线上每次调用更便宜，也不能自动抵消这一次制作与选优开销，复用规模要另算。

对结果强度的直接问答

问题。 把每题4次改成400次，就能证明未来项目上提高18.75个百分点吗？

答案。 同题成功概率可能估得更稳定，但仍只有原八题的来源覆盖；如果想推广到未来项目，应检查项目抽样、机制分布和来源相关性。重复次数不能替代新任务数量。

问题。 区间含0，是不是可以写“新提示无效、也不会伤害旧能力”？

答案。 两句都超出了依据。这个区间同时容纳零差异、负差和正差；没有确认收益也没有证明等效。还应单列U5的具体退化，不能让总均值掩盖机制失败。

问题。 只报告成功数差6题，缺少哪些解释？

答案。 这里是6次试次成功的差，并非6个独立任务被修好。还需任务分组、逐题差值、重复和缺失政策、近似条件，以及产生并评价输入政策的完整费用。
