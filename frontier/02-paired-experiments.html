Agent 前沿进阶能力增长、自主研究与自我改进

第 02 章｜多做了几题，能确定智能代理（Agent）改好了吗

本章概览

核心问题：同一方法在几次执行中多成功了，怎样判断这份差异能支持多强的改善结论？

关键概念：配对差（Paired Difference）对齐同一道题的两种方法；样本标准差（Sample Standard Deviation）描述观测差值的分散；标准误（Standard Error，SE）估计平均值的抽样波动；置信区间（Confidence Interval，CI）是有条件的区间构造。

关系主线：沿八题数据先在题内平均，再计算题间差值、离散和区间；最后改变来源与评分条件，判断下一项实验应增加哪些证据。

前情回顾：同一道题、同一份预算（Budget），仍会出现不同结果

第01章区分了修好项目产物（Artifact）与改善智能代理（Agent）的解题方法。它提出两种固定策略（Policy），也就是事先确定的处理规则：Q0使用原说明、按原流程处理失败；Q1在第一次执行失败后追加一次“比较原动作与子程序收到的参数，再定位边界”。改变进入下一次模型请求（Model Request），才有机会影响后续行为；这不涉及模型参数（Model Parameters）的更新。

本章沿用这两种策略（Policy）。两边采用同一模型（Model）M0、运行支撑（Agent Harness）H0，每次最多6次模型调用（Model Query）、8次工具调用（Tool Call）和120秒；新增说明与读取也占预算（Budget）。面对同一道题时，两边从相同、尚未修好的项目副本开始，权限（Permission）与成功条件相同。每次重新开始时，不继承前次补丁（Patch）、消息或跨题记忆（Memory）。

基础第26、40章已经给出比较所需的两个单位：任务（Task）是带要求与初态的问题；试次（Trial）是从规定初态出发的一整次执行机会，内部可以调用多次模型（Model）与工具（Tool）。一次试次（Trial）里的三次修改，不是三个独立任务（Task）；只有判定器（Grader）按成功条件取得有效结果，才能计为已知成功或失败。没有取得判断仍要保留未知，不能为方便计算把它填成失败。可从基础第26章与第40章回看这些关系。

现在增加一个问题：即使保持上述条件，两边重复执行仍可能出现不同结果。这次多成功的数量是已观察事实；换一批执行或未来项目，还会多成功多少？ 后一个问题需要理解抽样不确定性（Sampling Uncertainty），即有限观察随重新抽取题目和执行结果而产生的变化。

再定义重新抽样时会变化的量

现在才讨论推广。若目标只是描述这八题的这批给定记录，0.1875已经是确定的算术结果；若要推断未来任务（Task），就需要定义从哪些项目、以什么方式取得新题，以及每题怎样执行。

为解释公式，设想按某个固定的题目抽样和执行方案重新做整轮比较。用大写DiD_iDi​表示尚未观察的第iii个配对差（Paired Difference），它会随抽样变化，是随机变量（Random Variable）；小写did_idi​是本次表中已看到的一个值。用D‾=N−1∑iDi\overline D=N^{-1}\sum_iD_iD=N−1∑i​Di​表示随机的整批平均，本表的0.1875是它的一次实现。

E\mathbb EE是对可能结果及其概率（Probability）求加权平均；Var⁡\operatorname{Var}Var表示方差（Variance）；σd2\sigma_d^2σd2​是总体中的波动尺度，当前不知道它。前面的sd2s_d^2sd2​只是用有限观察估计这个未知量。将两者分开，才能解释“本表有多分散”与“重复整轮会怎样变化”。

标准误（SE）为什么要除以根号下的任务（Task）数

先增加明确条件：各DiD_iDi​可视为独立同分布（IID），且具有有限方差（Variance）σd2\sigma_d^2σd2​。独立意味着一项的随机波动不携带另一项的波动信息；同分布意味着各项来自同样的抽样机制，允许抽到难度不同的题，并不要求每题同样难。

在这些条件下，独立随机量相加的方差（Variance）等于各自方差（Variance）之和；把随机量乘一个系数，它的平方偏离会乘该系数的平方。因此：

Var⁡(D‾)=Var⁡ ⁣(1N∑i=1NDi)=1N2∑i=1NVar⁡(Di)=Nσd2N2=σd2N.\begin{aligned} \operatorname{Var}(\overline D) &=\operatorname{Var}\!\left(\frac1N\sum_{i=1}^{N}D_i\right)\\ &=\frac1{N^2}\sum_{i=1}^{N}\operatorname{Var}(D_i) =\frac{N\sigma_d^2}{N^2}=\frac{\sigma_d^2}{N}. \end{aligned}Var(D)​=Var(N1​i=1∑N​Di​)=N21​i=1∑N​Var(Di​)=N2Nσd2​​=Nσd2​​.​

开平方后，整批平均的波动尺度是σd/N\sigma_d/\sqrt Nσd​/N​。实际只能用sds_dsd​估计σd\sigma_dσd​，于是得到标准误（SE）：

SE⁡^(dˉ)=sdN=0.2587745848…8≈0.091491.\widehat{\operatorname{SE}}(\bar d) =\frac{s_d}{\sqrt N} =\frac{0.2587745848\ldots}{\sqrt8} \approx0.091491.SE(dˉ)=N​sd​​=8​0.2587745848…​≈0.091491.

后文把这个估计简称标准误（SE），约为9.15个百分点（pp）。样本标准差（Sample Standard Deviation）看一项观测差值的分散；标准误（SE）看整批平均随重新抽样的变化尺度。后者更小来自独立平均的条件，不能据此减少下一题自身的失败风险。

若U1/U2共享同一错误来源，它们可能一起偏高或偏低，独立相加的等式就不能直接用。一般表达式还包含协方差（Covariance），即两个随机量是否倾向同向偏离各自期望（Expectation）的量：

Var⁡(D‾)=1N2[∑i=1NVar⁡(Di)+2∑i<jCov⁡(Di,Dj)].\operatorname{Var}(\overline D) =\frac1{N^2}\left[ \sum_{i=1}^{N}\operatorname{Var}(D_i) +2\sum_{i<j}\operatorname{Cov}(D_i,D_j) \right].Var(D)=N21​[i=1∑N​Var(Di​)+2i<j∑​Cov(Di​,Dj​)].

Cov⁡(Di,Dj)\operatorname{Cov}(D_i,D_j)Cov(Di​,Dj​)表示第i,ji,ji,j项的协方差（Covariance），∑i<j\sum_{i<j}∑i<j​只让每对不同项出现一次；系数2来自展开平方时的两个交叉项。共同波动为正时，忽略这一项会低估整批平均的波动。这里没有估计每对题的值，只说明为什么“多复制几份相近题”不能自动获得同样可靠的缩小效果。

从标准误（SE）走到置信区间（CI），还缺什么条件

标准误（SE）提供波动尺度，还没有给出想保留多大范围。常见方法是用样本均值（Sample Mean）作中心，在两侧加减一个临界值（Critical Value）乘标准误（SE）；临界值（Critical Value）决定区间放宽到什么程度。

先明确本表的适用边界。 若差值是独立同分布（IID）的正态随机量，且总体方差（Variance）为正但未知，下面的t分布（Student's t Distribution）构造具有相应的精确覆盖性质。正态分布（Normal Distribution）是以均值为中心的连续钟形分布；t分布（Student's t Distribution）在有限样本时保留更厚的尾部，用于这里连总体波动也需要估计的情形。现实数据只能在条件合适时采用近似；八题教学差值有界、离散，且没有真实随机抽取，本章演示计算，不声称这张表已经满足95%覆盖条件。

先把t统计量（t Statistic）写出来，它用“观测中心距真实中心有多远”除以估计波动尺度：

T=D‾−μΔSd/N.T=\frac{\overline D-\mu_\Delta}{S_d/\sqrt N}.T=Sd​/N​D−μΔ​​.

TTT是随机的标准化差异；SdS_dSd​是每轮重新抽样所得的样本标准差（Sample Standard Deviation），其本次观测值才是sds_dsd​。在刚才的正态独立条件下，TTT服从自由度（df）为N−1N-1N−1的t分布（Student's t Distribution）。

“95%”约束方法，不给这次固定端点重新分配概率（Probability）

假设不断按同一种抽样方案重做比较，每次都会得到新的中心、波动估计和端点。在适用条件下，这些随机区间中约95%覆盖固定的总体平均差（Mean Difference）μΔ\mu_\DeltaμΔ​，这就是置信区间（CI）的重复覆盖含义。现在已经计算出的这一对端点，要么覆盖它，要么不覆盖；不能把固定未知量读成“有95%的概率（Probability）落在本次区间里”。

从正态条件转到实际智能代理（Agent）题目时，需要另查近似是否合理：题数很少、严重偏斜、来源相关或任务分布变化，都可能影响解释。换成重采样（Resampling）——从已有数据按规则重新抽取来估计变化的方法——也仍要保留正确分组并满足自身条件；方法名称不会增加新的独立观察。

即使暂按近似阅读，这条区间包含0，也只说明零差异尚未被排除。它还包含负值与明显正值，不能据此确认“无效”，更不能证明两方案等效。若采用要求是“总体至少提高5个百分点（pp）”，下端低于+5同样不够；而U5的观测退化还需要单独解释。

因此，本表平均多18.75个百分点（pp）、未来总体至少多5个百分点（pp）、所有旧题都不退化，是三份不同主张。 置信区间（CI）也不会自动消除未控制的资源差异，或评价材料参与调优所产生的系统偏差；后者在第03章继续展开。

四段参考代码怎样对应刚才的计算

下面四个Python块按顺序组成一个完整参考程序，输入是本章S/F表，输出是八个配对差（Paired Difference）、样本均值（Sample Mean）、标准误（SE）与端点。程序检查数据形状并重算算术；它不执行智能代理（Agent），不检验抽样代表性，也不自动处理未知评分（Unknown Score）。

第一步：保留一行一题，不只输入两个总成功数

每行依次保存题号、Q0四次结果、Q1四次结果。结构先保留自然对应关系；assert在本例检查恰有八道题、两侧都含四个已知结果。如果出现U，应进入后面的未知分支，不能用0替它通过检查。

import math

rows = [
    ("U1", "SSSF", "SSSS"),
    ("U2", "FSFF", "SSSF"),
    ("U3", "SSSS", "SSSS"),
    ("U4", "SFSF", "SSSF"),
    ("U5", "SSSF", "SFSF"),
    ("U6", "FFFF", "FSFS"),
    ("U7", "SFSF", "SFSF"),
    ("U8", "FSFF", "FSSF"),
]
repetitions = 4
assert len(rows) == 8
for _, q0, q1 in rows:
    assert len(q0) == len(q1) == repetitions
    assert set(q0 + q1) <= {"S", "F"}

每个字符串中的四个字符表示四个完整试次（Trial），不是四次函数调用，也不是四条测试断言。真实记录还需初态、时间、费用和评分状态；本程序只接收已经按共同规则整理好的教学输入。

第二步：先题内求比例，再形成配对差（Paired Difference）

count("S")先数一侧的成功数，除以该侧重复数得到题内比例；b-a保持Q1减Q0的方向。by_task让题号与结果继续相连，U5的负值不会在汇总后消失。

by_task = []
for task_id, q0, q1 in rows:
    a = q0.count("S") / repetitions
    b = q1.count("S") / repetitions
    by_task.append((task_id, b - a))
d = [difference for _, difference in by_task]
n = len(d)
mean = sum(d) / n
print("differences=", d)

这一段给出[0.25, 0.5, 0.0, 0.25, -0.25, 0.5, 0.0, 0.25]。n现在是8，mean是0.1875；如果重复数不同，先题内平均的结构仍然需要保留，不能把分母改成所有执行数量。

第三步：从平方偏离走到标准误（SE）

squared_sum对应前文0.46875，variance对应除以7后的样本方差（Sample Variance）。最后的variance/n才把单项波动换成平均波动的估计，仍以独立同分布（IID）的解释条件为前提。

squared_sum = sum((value - mean) ** 2 for value in d)
variance = squared_sum / (n - 1)
sd = math.sqrt(variance)
se = math.sqrt(variance / n)
assert math.isclose(squared_sum, 0.46875)
print(f"mean={mean:.6f}; SE={se:.6f}")

这段不会因为可以计算就认定题目独立。它输出的SE=0.091491是此前条件下的尺度估计，不是已测出来的真实长期误差。

第四步：明确临界值（Critical Value）属于哪个条件

本例把已核准的t临界值（Critical Value）写成常数；它只对应双侧95%和自由度（df）7。这里再次固定n==8，避免修改题数后悄悄沿用同一常数。

assert n == 8  # 下一个常数只用于本例的自由度 df=7。
t_critical = 2.364624251
half_width = t_critical * se
low = mean - half_width
high = mean + half_width
print(f"interval=[{low:.6f}, {high:.6f}]")

这四段参考代码按顺序实际运行，完整输出如下。另一次独立算术核对得到相同的中心、标准误（SE）和区间端点；两项都只计算教学数据，不构成模型（Model）实验：

differences= [0.25, 0.5, 0.0, 0.25, -0.25, 0.5, 0.0, 0.25]
mean=0.187500; SE=0.091491
interval=[-0.028841, 0.403841]

改变来源或评分条件，原判断怎样收窄

同源变体增加了文件名，没有同样增加独立信息

先单独改变来源条件：假设U1/U2来自同一模板，只改了目录名；U3/U4也共享一份入口模板。它们可能共享难点与错误机制，此时不能再把八题视作八份独立来源。来源组（Source Group）是保存这种共同来历的分组，例如把同一项目或模板派生的题放在一起。

若目标是推广到新项目，就要在项目或相应来源组（Source Group）层次组织数据划分及分析。用重采样（Resampling）时，抽到一个来源组（Source Group），应一并带上其相关题目及Q0/Q1结果，不能逐行拆散。组数少时，这种操作仍不能创造更多独立证据；本章没有提供新的可靠区间。

执行顺序也是另一个条件。真实实验可以预先交错安排或随机安排Q0/Q1，减少“Q0全在服务繁忙时执行”的时间混杂，并记录服务事故。但这不会解除同源题的相关性，也不会保证两侧某次模型调用（Model Query）天然对应；不同问题仍需各自处理。

未知评分（Unknown Score）改变的首先是我们知道什么

再单独改变评分条件，回到原八题给定记录，不继续采用上一小节新增的同源假设。假设Q1在U5第2次的评分服务失败，将原格F改成未知U。这里U表示没有有效任务判定，不能读成已经失败。Q1现在有22个成功、9个有效失败、1个未知。

有有效评分（Valid Score）的31次中，条件成功率（Conditional Success Rate）为：

QQ1=2222+9=2231≈70.97%.Q_{Q1}=\frac{22}{22+9}=\frac{22}{31}\approx70.97\%.QQ1​=22+922​=3122​≈70.97%.

QQ1Q_{Q1}QQ1​只以有分数的执行为分母；Q0的16/32没有排除同一范围。因此即使两数都算对，也不能直接把它们的差称为全部计划试次（Trial）的收益。失去评分的这一格是否更容易失败，当前仍不知道。

若只枚举这一个未知的最终任务真值可能为0或1，全部32次的成功比例有逻辑上下界（Logical Bounds）：

2232≤pQ1,batch≤22+132,68.75%≤pQ1,batch≤71.875%.\frac{22}{32}\le p_{Q1,\mathrm{batch}}\le\frac{22+1}{32}, \qquad 68.75\%\le p_{Q1,\mathrm{batch}}\le71.875\%.3222​≤pQ1,batch​≤3222+1​,68.75%≤pQ1,batch​≤71.875%.

pQ1,batchp_{Q1,\mathrm{batch}}pQ1,batch​在这里表示这批32次的最终真值比例，不是未来任务（Task）的概率（Probability）。再减去Q0已知的16/32，得到：

0.1875≤Δbatch≤0.21875,0.1875\le\Delta_{\mathrm{batch}}\le0.21875,0.1875≤Δbatch​≤0.21875,

即差值介于18.75与21.875个百分点（pp）之间。Δbatch\Delta_{\mathrm{batch}}Δbatch​只描述同一批执行的差；逻辑上下界（Logical Bounds）没有指定未知格为0或1的概率（Probability），也没有描述未来抽样波动，因此不是置信区间（CI）。

如果问题改为截止前是否确认交付（Confirmed Delivery），再假设表中所有S都在截止前确认，Q1就是22/32，Q0为16/32。U在这个新事件上贡献0，表示截止前未确认成功；原始任务评分仍未知。后来补出S，可以更新最终真值比例，却不能回填过去的按时交付。

来源相关性和未知评分（Unknown Score）约束不同关系：前者影响独立信息量，后者影响我们知道哪些真值。删去U不解决来源问题，保留所有行也不会自动补出U的判断。真实记录要同时保留任务（Task）身份、试次（Trial）、初态、评分状态、时间、费用及预先约定的处理规则。

下一项实验该增加新题，还是增加重复

回到原先全部有分数的八题表。假设还够新增16次单侧执行，也就是8对Q0/Q1比较。有两种同数量的安排：在原八题各补一对；或另外取八个来源清楚的新题，每题两侧各做一次。在执行分布保持稳定、增加的试次（Trial）提供独立或有效新增信息时，前者有助于让已选题的成功概率（Probability）估计更稳定；后者增加题目覆盖，但每道新题只执行一次，结果本身也会较不稳定。

采用哪一种，先看缺口。若同题反复结果相近，而不同机制有明显正负差，新增独立题目并追查U5这一类退化更有帮助。若题间差异不明显，却在同题上反复变化，补重复有助于分清执行波动。本表不足以精确分解这两份方差（Variance），所以上述是设计判断，不是已经证明的最优预算（Budget）分配。 特别是要推广到未来项目时，把原题从4次改为400次，仍没有增加新的项目来源。

把新增信息放回完整成本（Total Cost）

为比较代价，明确本例的费用条件：每次完整执行连同评分固定为2个教学费用点，失败也收费；本表所有账单已经结清。两种策略（Policy）各有32个试次（Trial），共64次单侧执行。Q1说明的制作另花6点，因此本轮完整成本（Total Cost）为：

Cexecution=8×4×2×2=128,Ctotal=Cexecution+Cpreparation=128+6=134.\begin{aligned} C_{\mathrm{execution}}&=8\times4\times2\times2=128,\\ C_{\mathrm{total}}&=C_{\mathrm{execution}}+C_{\mathrm{preparation}} =128+6=134. \end{aligned}Cexecution​Ctotal​​=8×4×2×2=128,=Cexecution​+Cpreparation​=128+6=134.​

第一行四个因子分别是8题、每题每侧4次、两种策略（Policy）和每次2点；Cpreparation=6C_{\mathrm{preparation}}=6Cpreparation​=6是制作费用。这些都是教学计量，不是真实服务价格。不能只给Q1的22次成功收费，其他执行也为取得这份比较消耗了资源。

新增8对比较各花4点，总增量32点；若实际还需要制作新任务（Task）、修复评分服务或人工核对，就要另外计入。这里32点只比较已提供相应题目和评分条件下的新增执行费用，不把尚未定价的工作当免费。

在真实系统中还需记录墙钟时间（Wall-clock Time），即从开始到交付的实际经过时间；并行执行时，它与各项活动时长之和不同。费用省了一点，也不能直接解释为用户少等了一秒。原方法制作与选择的固定开销，要结合未来复用规模另算，下一章继续处理这件事。

改变报告方式，再作参考判断

问题。 每题重复400次，就能证明未来项目提高18.75个百分点（pp）吗？

参考答案。 它可能更准确地描述原八题在固定条件下的成功概率（Probability），但未来项目的范围仍未覆盖。若题目来自相同模板，还要保留来源组（Source Group）；重复数不能替代独立任务（Task）数。先确认要推广到哪里，再决定下一批应补什么。

问题。 样本标准差（Sample Standard Deviation）约25.88个百分点（pp），标准误（SE）却约9.15个百分点（pp），哪一个才正确？

参考答案。 两者回答不同问题。前者描述观测配对差（Paired Difference）的分散，后者在独立同分布（IID）解释下估计八题平均的抽样变化。将其除以根号8不会使每道题都更稳定，也不证明未来题只在9.15个百分点（pp）范围内变化。

问题。 教学区间包含0，能写“新说明无效、也不会伤害旧能力”吗？

参考答案。 不能。即使先接受该近似，区间仍同时容纳零差异、负差和正差；它没有确认收益，也没有证明等效。最低采用收益若是+5个百分点（pp），下端仍不足；U5的具体退化也不能被总体平均掩盖。还须保留本表不构成真实95%覆盖实验的限制。

问题。 只写“多修好了6题”，省略了什么？

参考答案。 这里22减16是6次试次（Trial）成功数的差，涉及八道题上的重复，不是新增修好六个独立任务（Task）。完整解释还包括逐题对应、题内重复、未知处理、抽样条件与134点的完整成本（Total Cost）。同样，条件率22/31不能替代有一个未知时的全部32次口径。
