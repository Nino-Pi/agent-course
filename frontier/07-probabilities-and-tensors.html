Agent 前沿进阶能力增长、自主研究与自我改进

第 07 章｜概率和张量怎样描述一次预测

本章概览

核心问题：模型给出的几个数怎样成为下一 token 的概率，训练程序又在什么位置、按什么单位汇总它们？

关键概念：Logit：归一化前的候选分数；条件概率：给定当前输入后的预测分布；交叉熵：按监督分布计算的负对数概率；KL：有方向的分布差异；张量：按多个维度排列的数；Mask：指定参与计算的位置。

关系主线：从三候选模型算出概率与对数概率，再比较两份分布；把单位置扩展到批次、序列和词表，辨明前缀对齐、位置掩码与平均单位，为下一章的参数更新准备同一套数字。

本章只硬需第01章的“改变对象与实际消费者”。它是模型训练路线的数学入口，可以从第01章直接进入，不要求先读完固定模型策略、数据生成或旧46章选读。这里先算清预测与信号的含义，下一章再让这些信号实际改变权重。

1. 先把一次预测缩到能逐项看清

另设一个教学情境：Agent 已读取并修改目标文件，规定的测试还没有执行；当前允许并应当选择“运行测试”。这不是第01章空格路径任务的真实续跑，也没有调用模型或工具。我们用一个公开全部数值的条件模型，观察“应该选测试”与“当前更可能选什么”之间的差别。

输出词表人为缩成三个符号：<READ>、<TEST>、<DONE>，编号分别为0、1、2。在这个教学模型里，每个符号恰好是一个 token。Token 是模型处理的序列单位；真实工具名、JSON 或一句话通常不能直接按这里的三个符号计算。

当前输入由一个固定编码器转成特征向量 h=[1,1]：第一维是常数，第二维表示本例所需的当前材料已经可见。编码器不参与本次训练；模型全部可训练数值只有下面的矩阵 W。它是语言模型输出头的最小数值替身，没有隐藏的 Transformer 或预训练能力。

设 D=2 是特征维数，V=3 是词表大小。公式把 h 视为 [D,1] 列向量，W 是 [V,D] 矩阵；代码以两个数的一维列表保存 h。

W = [[ 1, 0],
     [ 0, 0],
     [-1, 0]]
h = [1,1]

矩阵乘法 z=W h 的每个输出，都是 W 的一行与 h 对应元素相乘后相加：

z_READ =  1×1 + 0×1 =  1
z_TEST =  0×1 + 0×1 =  0
z_DONE = -1×1 + 0×1 = -1

所以 z=[1,0,−1]：公式中是 [V,1] 列向量，代码保存为形状 [V] 的一维列表。这些 logits 是未归一化分数，可以为负，也不需要合计为1。分数1没有“百分之百”的含义；先要把三个候选放进同一个分布。

真实语言模型会用实际 token 前缀计算更高维的表示，再产生整个词表的分数。我们保留的数学接口是“当前输入 → h → z”，缩小的是编码器与词表，不能据此判断真实模型是否理解文件、权限或测试结果。

2. 从分数得到概率，并说明概率依赖什么

Softmax 对同一个预测位置的词表维做归一化。候选 v 的概率为：

p_v = exp(z_v) / Σ_{j=0}^{V−1} exp(z_j)

v、j 都是候选编号；exp(x)=e^x 为指数函数。先把每个分数变成正数，再除以全部候选的指数和，所以各概率非负且合计为1。

候选 分数 z exp(z) 概率 p
READ 1 2.718282 0.665241
TEST 0 1.000000 0.244728
DONE −1 0.367879 0.090031
合计 无须归一化 4.086161 1.000000

如果使用贪心选择，即选概率最大的候选，模型会选择 READ；本例的监督却要求 TEST。按分布采样也可能选到 TEST，但概率约0.245不保证某一次会选中。这里没有实际随机采样，也不把候选概率当成任务成功率。

这个分布完整写作 p_W(x_i | c_i)：W 是当前权重，x_i 是第 i 个输出 token，c_i 是生成它时实际可见的条件。条件可以包含用户目标、工具结果和已经生成的前缀。下标 i 按 token 位置计数，不是一次模型调用或一个环境动作的编号。

例如生成 TEST 调用时，还不能把“测试已经通过”当条件。调用执行后得到的结果属于下一次输入组织的材料。条件换了，概率也可以改变；不能把同一张三个数的表沿着整个任务重复使用，并声称它描述了真实生成过程。

为什么要保存对数概率

本册用自然对数 ln，其信息量单位是 nat。对数概率不是另一种概率：p 在0到1之间时，ln p 不大于0。本例三项分别是：

ln p = [−0.407605964, −1.407605964, −2.407605964]

概率越小，对应的负对数 −ln p 越大。本例 TEST 的负对数概率为1.407605964 nat。它稍后会成为“一份确定目标”的训练损失，但还没有乘上任务奖励，也没有表示成功或失败。

对数还有一个便利：一段输出的条件概率相乘后，可以改写为对数相加。

p(x_1,…,x_n | c) = Π_{i=1}^n p(x_i | c,x_<i)
ln p(x_1,…,x_n | c) = Σ_{i=1}^n ln p(x_i | c,x_<i)

x_<i 表示这一段已经生成的 token；n 是这段输出长度。公式描述同一段自回归输出，前缀在段内按生成顺序增长。跨 Agent 调用时若发生摘要或重新检索，新输入须按实际调用重建，不能默认仍是旧全文的延长。

为了只演示相乘与相加，另给第二个条件分布：第一步 TEST 概率为上面的0.244728471；在新前缀下，第二步 DONE 概率另设为0.8。后一个数不是由本例 W 推出来的，也不表示工具真的通过了测试。两步概率为0.195782777，对数概率约−1.630749516。把第一张表的 DONE 概率0.090031直接拿来相乘，会换掉第二步的条件。

数值相同的公式，程序可能算坏

给三个 logits 都加1000，数学上概率不变，因为分子与分母会同时乘上 e^1000。直接算 exp(1001) 却可能溢出。常见稳定算法先减去最大分数，使最大的指数成为1。

下面是可执行参考，直接计算 log-softmax，再按需取指数：

import math

def log_softmax(z):
    top = max(z)
    log_den = top + math.log(sum(math.exp(v - top) for v in z))
    return [v - log_den for v in z]

z = [1.0, 0.0, -1.0]
log_p = log_softmax(z)
p = [math.exp(v) for v in log_p]
shifted = [math.exp(v) for v in log_softmax([v + 1000 for v in z])]
print([round(v, 6) for v in p])
print(max(abs(a - b) for a, b in zip(p, shifted)) < 1e-12)

实际输出是 [0.665241, 0.244728, 0.090031] 与 True。不要先把极小概率舍入成0，再求对数；数学上有限的负对数也会被这样变成无穷。

3. 一份监督与两份分布怎样比较

先用确定目标 TEST。用 q=[0,1,0] 表示监督分布：只给 TEST 权重1，其余为0，这叫 one-hot（独热）目标。交叉熵按监督分布对预测的负对数概率加权：

H(q,p) = −Σ_v q_v ln p_v

对当前 one-hot 目标，只有 TEST 项留下，所以交叉熵就是1.407605964 nat。它比较“当前分布对指定目标给了多大概率”，并不判断指定目标本身是否正确。把不该做的动作标成目标，也能算出一个完全合法的损失。

现在明确改变监督条件：另一位教学教师对同一前缀、同一词表给出软目标 q=[0.2,0.7,0.1]。这三个数是给定的监督概率，不是从一次采样动作猜出来的。模型预测 p 仍用原来的三项。

KL 散度比较两个分布，必须写清方向：

D_KL(q || p) = Σ_v q_v ln(q_v / p_v)

左边的 q 决定求和权重；p 出现在比值分母。当前各项都大于0，两方向都能正常计算：

量 本例结果，单位 nat 含义
H(q,p) 1.307606 按教师 q 加权的预测负对数概率
H(q)=−Σq ln q 0.801819 教师分布自身的熵
D_KL(q‖p) 0.505787 按 q 加权的分布差异
D_KL(p‖q) 0.532860 换成按 p 加权后的另一方向

H(q)称为熵，即按q自身概率抽样时的平均负对数概率；完全确定的分布只会抽到概率1的结果，因此熵为0。

展开比值的对数，可得 H(q,p)=H(q)+D_KL(q||p)。本例为 1.307606≈0.801819+0.505787。当 q 固定、只优化 p 时，H(q) 是常数，因此这两个优化目标仅差常数；若 q 也随被优化的参数变化，就不能直接套用“固定教师”的结论。

KL 非负，但不是通常意义上的对称距离。还要注意零概率：若 q_v 为0，q_v ln(q_v/p_v) 按极限取0；若 q_v 大于0而 p_v 为0，该方向的 KL 为无穷。于是 one-hot 目标的 D_KL(q||p) 可以有限，反向 D_KL(p||q) 却可能无穷。偷偷加一个小数避免报错，也改变了原分布与目标。

精确计算这里的全词表 KL，需要同一输入和对齐词表上的完整分布。只有一次输出、所选 token 的概率或一段文字评价，不能直接补出其余概率。后续方法若使用采样估计或近似，会另行说明采样者、方向和适用条件。

4. 从一个位置扩展到一个批次

训练通常一次处理多个条件样本和多个位置。张量就是按多条轴组织的数；本章用三个维度标明它们各在数什么：

记号 本章含义 示例大小
B 批次里的条件样本；这里每个对应一次模型调用 2
L 对齐后、补齐到同长度的目标位置数 3
V 每个位置的候选词表大小 3

分数张量 Z 的形状为 [B,L,V]。Z[b,l,v] 表示第 b 个样本、第 l 个目标位置、候选 v 的分数；目标编号 Y 与损失掩码 M 都是 [B,L]。Softmax 只沿最后的词表维求和，不把不同样本或不同位置混进同一个概率分布。

这里的“对齐”很关键。另用一般语言模型的角色示意序列 [P0,P1,A0,A1,EOS]：P 表示给定前缀，A 表示要学习的回答，EOS 是结束符。它们仅为位置标签，不是前面三符号词表的新增真实 token。

如果原始长度为 T，常见做法是用前 T−1 个输入位置预测后 T−1 个目标位置：

输入末位：P0   P1   A0   A1
预测目标：P1   A0   A1   EOS
损失掩码：0    1    1    1

所以此时 L=T−1。读到 P1 后开始预测 A0，读到 A0 后预测 A1；训练时向后提供已有参考前缀的做法称为 teacher forcing（教师强制）。不能拿读到 A0 后的分数去给 A0 自己打分，那会让输入已经包含答案。若调用的训练 API 已内部移位，再手动移一次也会错位。

损失掩码与可见性是两件事

M 中的1表示“此目标位置直接贡献本项损失”，0表示“不贡献”。前缀预测位置和 padding（补齐位置）常被排除。Loss mask 不负责决定输入能看见谁：attention mask（注意力掩码）可标出有效输入位置，causal mask（因果掩码）限制当前位置不能偷看未来，具体接口按模型定义。

即使某前缀目标的 M 为0，它仍可能作为输入影响后面的预测。若编码器也在训练，后面监督位置的梯度——损失对参数变化的敏感度，下一章会详算——还可能经过计算图影响前缀的表示参数。不能据此宣布“mask 为0的 token 对应的参数完全冻结”。冻结的是参数更新资格，屏蔽的是这项损失的位置，二者属于不同层。

还要保留条件来源。工具返回“读取失败”，事后换成“读取成功”后即便该段 M 全为0，后续动作的输入也已经被改变。正确的掩码不能修复伪造的前缀。

5. 同一批数，为什么能得到三个平均值

现在只做聚合演算，暂把词表改成三个普通符号 a、b、c，编号仍为0、1、2；不把它们解释成工具动作。两次条件调用各有三个对齐槽位，每个位置给定同样的 logits [1,0,−1]。这批数据用于看清权重，独立于下一章那一个 TEST 样本的更新。

第一列目标来自给定前缀，不优化；第二次调用最后一列是 padding，标签0只是填充值。所有数字如下：

Y = [[0,1,2],     M = [[0,1,1],
     [0,0,0]]         [0,1,0]]

先逐位置计算 ℓ_bl=−ln p_bl,Y_bl。b 是调用，l 是对齐目标位置，Y_bl 用于选出实际目标 token 的那一项概率。得到：

ℓ = [[0.407605964,1.407605964,2.407605964],
     [0.407605964,0.407605964,0.407605964]]

M 选中的三项为1.407605964、2.407605964、0.407605964，总和4.222817893；两次调用分别含 N_b=Σ_l M_bl 个参与 token，N 为 [2,1]。

按 token 等权，分母是三个参与 token：

L_token = Σ_b Σ_l M_bl ℓ_bl / Σ_b N_b
        = 4.222817893 / 3 = 1.407605964

先在调用内按 token 平均，再让调用等权：

L_call = (1/B) Σ_b [Σ_l M_bl ℓ_bl / N_b]
       = (1.907605964 + 0.407605964) / 2 = 1.157605964

前一种单位是每参与 token 的平均负对数概率；后一种平均了每次调用的 token 均值。前者给两次调用总权重2/3与1/3，后者各1/2。它们改变了优化对象的权重，没有凭空增加一次任务成功。

可执行参考如下；它承接本章 log_softmax，核心聚合直接展开：

Z = [[[1.0, 0.0, -1.0] for _ in range(3)] for _ in range(2)]
Y = [[0, 1, 2], [0, 0, 0]]
M = [[0, 1, 1], [0, 1, 0]]
sums, counts = [], []
for b in range(2):
    losses = [-log_softmax(Z[b][l])[Y[b][l]] for l in range(3)]
    sums.append(sum(m * loss for m, loss in zip(M[b], losses)))
    counts.append(sum(M[b]))
if any(n == 0 for n in counts):
    raise ValueError("本例拒绝没有监督位置的调用")
print(sum(sums) / sum(counts))
print(sum(s / n for s, n in zip(sums, counts)) / len(sums))

实际结果四舍五入后为1.407605964与1.157605964。空掩码分支也已用一条 M 全0的输入核对，会拒绝。其他训练设计可以预先规定排除空样本，但不能临时把分母改成1、以零损失把它当作学习良好。

一个实际会出现的错误是：先把被屏蔽位置设为0，再对全部 B×L=6 个槽位求 .mean()。本例会得到0.703802982，分母包含 padding，改变补齐长度就会改变数值。若声明的目标是参与 token 均值，这个实现不符合目标。

Rollout 指一次完整任务尝试，可以含多次模型调用。要让任务尝试等权，还须保留每个 token 属于哪次尝试：用 ρ 标记尝试，R 为尝试数，Nρ 为其中参与 token 总数，才可写 L_rollout=(1/R)Σρ[(1/Nρ)Σ_i ℓρi]。这里 i 只遍历该尝试参与的位置。B不自动等于R，调用等权也不自动等于任务等权；旧46章的切片反例讨论的正是这一层差异。

实际接训练库还要核对布局。比如把 [B,L,V] 摊成 [B×L,V]，目标摊成 [B×L]，才符合把第二维当类别的相应接口；不能仅凭张量有三个维度就认为库会自动找到词表轴。输入若要求 logits，就直接传 logits，不再预先 softmax 一遍。

6. 从数字回到数据判断

问题。 把所有候选分数都提高1000，能说模型对 TEST 更有把握了吗？

答案。 不能。Softmax 依赖候选之间的相对分数；这个共同平移不改变概率。数值稳定实现会得到原分布，直接指数溢出只是程序故障。

问题。 一条轨迹只有模型实际选中 token 的概率，是否足够得到本章的全词表 KL？

答案。 不足。当前公式要对整个对齐词表求和，还缺未选候选的概率。特定算法可以另定义采样估计，但要给出其条件，不能将缺失值补成0后沿用精确 KL 的结论。

问题。 两种平均都没有算错，为什么仍要选定一种？

答案。 因为它们决定哪些样本更影响更新。按 token 平均让长输出贡献更多总权重，按调用等权则先归一化长度；如果研究单位是完整尝试，还要进一步保留 rollout 分组。数字正确不能替代目标选择。
