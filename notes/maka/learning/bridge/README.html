写入窗口的判断与解释

“没有 observation”不能推出“没有 effect”：文件写入发生在环境执行期间，而 trajectory 由后续保存动作写入，两者之间存在进程被终止的窗口。

第06章的实际 README 说明文件是否已改变，旧 messages 说明 Agent 留下了哪些观察，控制进程的退出结果说明执行如何停止。三者共同解释写入窗口，单个 PASS 标记不能代替这些状态。

第07章/第08章 提供记录缺口与状态判断的案例解答。第11章将这些问题展开为 Maka 的系统组成。
